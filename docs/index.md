Koyori の文書は、読み手ごとに 5 つの群に分ける。今あるのは「開発者向け」だけである。

| 群 | 読み手 | 書くこと |
|---|---|---|
| はじめに | 全員 | Koyori の全体像、用語、画面の歩き方 |
| 使い方 | 利用者 | 操作の手順 |
| セルフホスト | 運用者 | 必要なもの、環境変数、外部サービスの登録手順、更新 |
| 連携と API | CLI・PAT・外部ツールを使う人 | アクセストークン、CLI、Webhook、API の入口 |
| [開発者向け](/dev) | 開発者 | [仕様](/dev/features)、[フロントエンド](/dev/frontend)、[設計の記録](/dev/design)、[開発手順](/dev/development) |
