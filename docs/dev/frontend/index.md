複数の画面にまたがるフロントエンドの実装をまとめた群である。個々の画面は、[仕様](/dev/features)の各ページの画面の節に書く。

- [URL](/dev/frontend/url-spec)と[パンくず](/dev/frontend/breadcrumbs)は、画面の位置の表し方を書く
- [認証フォーム](/dev/frontend/auth-forms)は、サインアップとサインインのフォームを書く
- [KFM の描画](/dev/frontend/kfm-phase1-implementation)は、本文のレンダラを書く
- [PWA](/dev/frontend/pwa)は、Web の task を standalone のウィンドウで開く仕組みを書く
