ログインの方法と、それを守る仕組みをまとめた群である。

- [2 段階認証](/dev/features/auth/2fa)は、TOTP、リカバリーコード、テナントによる強制を書く
- [OAuth ログイン](/dev/features/auth/oauth)は、外部のアカウントによるログインと連携を書く
- [パスキー認証](/dev/features/auth/passkeys)は、WebAuthn によるパスワードなしのログインを書く
- [パスワードのリセットと変更](/dev/features/auth/password-reset)は、忘れたときの再設定とログイン中の変更を書く
