機能の現在の振る舞いを、機能ごとにまとめた群である。API の形、認可、データの列の定義元はここに置く。

- [タスク](/dev/features/tasks)は、タスクとその周辺の機能をまとめる
- [認証](/dev/features/auth)は、ログインの方法をまとめる
- [アカウント設定](/dev/features/account-settings)と[サービス管理者と監査ログ](/dev/features/admin)は、利用者自身の設定とサービス全体の管理を書く
- [レビュー指摘管理](/dev/features/review-findings)と [Drive](/dev/features/drive)は、タスクの外にある機能を書く
- [テナントの BOT アカウント](/dev/features/tenant-bots)は、テナントが持つ自動化用のアカウントを書く
