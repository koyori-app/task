Koyori を直す開発者に向けた群である。次の 4 つに分かれる。

- [仕様](/dev/features)は、機能ごとの現在の振る舞いを書く
- [フロントエンド](/dev/frontend)は、画面をまたぐ実装を書く
- [設計の記録](/dev/design)は、判断の理由と比較した案を残す
- [開発手順](/dev/development)は、スキーマの変更と依存の管理の手順を書く
