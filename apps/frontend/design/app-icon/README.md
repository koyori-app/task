# アプリの icon の元の絵

`source.png` は task のアプリの icon の元の絵です（TASK-299）。
1254×1254 の RGBA で、背景は透けています。
仮の絵で、必要になったら清書します。

ここから焼いた物は次の六つです。

| file                               | 寸法    | 性質   |
| ---------------------------------- | ------- | ------ |
| `public/pwa/apple-touch-icon.png`  | 180×180 | 不透明 |
| `public/pwa/icon-192.png`          | 192×192 | 不透明 |
| `public/pwa/icon-512.png`          | 512×512 | 不透明 |
| `public/pwa/icon-maskable-512.png` | 512×512 | 不透明 |
| `public/favicon-16.png`            | 16×16   | 透け   |
| `public/favicon-32.png`            | 32×32   | 透け   |

## 焼き方

```sh
uv run --with pillow python apps/frontend/design/app-icon/build.py \
  apps/frontend/design/app-icon/source.png <出力の dir>
```

出力の六つを、上の表の場所へ同じ名で置きます。

## 焼く時の決め

- 絵の外には、alpha の低い点が薄く散っています。絵の範囲は alpha が 128 以上の画素で決め、散った点は切り出しで落とします。
- 絵を正方の中心へ置き直します。元の絵の中で、絵は中心から少しずれています。
- 透けは白（`PWA_BACKGROUND_COLOR` と同じ）で埋めます。iOS は透けを黒で埋めるので、透けたまま出すと角が黒くなります。
- 札の地は淡い藤色で、白との対比は 1.1 から 1.3 しかありません。白の地では札の縁が消えるので、淡い影を足して札の輪郭を見せます。地の色は変えません。
- 通常の icon は、絵の長い辺を icon の 80% にします。
- maskable は、OS が丸や角丸に切ります。絵の中心から最も遠い画素が、安全域（直径 80% の円）の 96% の内に収まるまで縮めます。
- favicon は透けたまま出し、絵を切り出さずに全体を縮めます。この絵は、淡い札と、その上に重なる青と紫の二本の帯で一つの形になっています。帯の端は札の右上と右下の角まで届き、札の右側の輪郭を兼ねているので、帯だけを切り出すと札の角丸の外形が失われ、別の形になります。
- 16px では、明るいタブで札の縁が淡くなり、札の上の二本の線は滲みます。それでも青と紫の二本の帯は色の塊として見分けられ、札と帯で作る全体の形は保たれます。32px では明るいタブでも暗いタブでも、札、二本の線、二本の帯がそれぞれ見分けられます。
